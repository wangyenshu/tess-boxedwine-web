Tess runs here as the unregistered evaluation version: everything works except saving, exporting and printing. To unlock them, buy a license and enter your name and code under File > Register... (the registration is kept in this browser).

First start: Tess asks for an interface language and shows its license agreement, then a reminder screen whose buttons change places each time; pick Continue.

The 3D views (cone, cylinder, torus) are drawn by Mesa's software OpenGL inside the emulator, so they take a few seconds to appear. They need a tiling with translations, e.g. one from File > New Heesch Tiling.

Add ?resolution=1280x1024 to the URL for a bigger screen.
